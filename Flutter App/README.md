# GPS Vehicle Tracking Assessment

This repository contains a full stack assessment implementation for a GPS-based vehicle tracking system.

- Backend: FastAPI, SQLAlchemy, PostgreSQL, JWT auth.
- Frontend: Flutter mobile app.
- Bonus: Docker Compose with PostgreSQL, Mosquitto MQTT, and GPS simulator.
